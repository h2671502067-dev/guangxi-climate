================================================================================
          广西壮族自治区气象数据完整建模分析报告 (2005-2025)
================================================================================

数据来源: NASA POWER (地面气象) + NCEP/NCAR R1 (高空再分析) + MODIS NDVI (植被)
数据区域: 广西8个代表性城市 (南宁/桂林/柳州/梧州/北海/百色/河池/防城港) 全省平均
分析时间范围: 2005-01 - 2025-12 (共252个月度观测)
数据维度: 15个气象指标
分析工具: Python (pandas, scipy, scikit-learn, statsmodels, matplotlib)

================================================================================
第一章 数据概述与预处理
================================================================================

1.1 数据集基本信息
----------------------------------------
  样本量: 252条月度记录
  特征数: 15个气象变量
  时间跨度: 2005-01 至 2025-12
  缺失值处理: 线性插值 (Linear Interpolation)
    对时间序列中缺失值 x_t, 若 x_{t-1} 和 x_{t+1} 已知:
    x_t = x_{t-1} + (x_{t+1} - x_{t-1}) × (t - t_{t-1}) / (t_{t+1} - t_{t-1})
    边界处采用前向/后向填充 (forward/backward fill)

1.2 核心气象指标分类
----------------------------------------
  温度类 (7项): 平均气温、最高/最低气温、气温日较差、露点温度、地表温度、高温指数
  湿度类 (3项): 相对湿度、比湿、风寒指数
  气压风类 (5项): 气压、10m/50m风速、最大风速、风向
  降水蒸散类 (4项): 降水量、蒸散发、陆地蒸发、参考蒸散量
  辐射云量类 (6项): 短波/长波/光合有效/UVA/UVB辐射、总云量、日照时数(估算)
  土壤类 (3项): 根区/剖面/表层土壤湿度
  干旱指数 (4项): SPI-1m/3m、SPEI-1m/3m
  高空衍生 (7项): K指数、Showalter指数、整层水汽通量、各层温度与比湿
  植被 (1项): NDVI归一化植被指数
  周期编码 (2项): 月份 sin/cos

第四章 时间序列分解与平稳性检验
================================================================================

数学方法:
  加法分解模型: X(t) = T(t) + S(t) + R(t)
    T(t): 趋势分量 (移动平均提取)
    S(t): 季节分量 (周期=12个月)
    R(t): 残差分量 (随机波动)

  ADF检验 (Augmented Dickey-Fuller):
    H₀: 序列存在单位根 (非平稳)
    检验回归: Δyₜ = α + βt + γyₜ₋₁ + Σ δᵢΔyₜ₋ᵢ + εₜ
    若 p < 0.05, 拒绝H₀, 序列平稳

----------------------------------------
  ADF统计量: -3.0302
  p值: 0.032166

  结论: 序列平稳 (拒绝H₀)
  分解结果:
    趋势分量: 2006-2025年间气温呈微弱上升趋势
    季节分量: 典型正弦型季节波动, 7月最高, 1月最低
    残差分量: 大部分在±3°C内, 季节模型拟合较好

4.2 降水时间序列分解

5.1 SARIMA气温预测模型
----------------------------------------
数学方法:
  SARIMA(p,d,q)(P,D,Q)_s 模型:
    Φ(B^s)φ(B)(1-B)^d(1-B^s)^D yₜ = Θ(B^s)θ(B) εₜ
    B: 后移算子, s=12 (月度数据季节周期)
    模型选择: AIC = -2ln(L) + 2k (越小越好)

  模型规格: SARIMA(3, 1, 4)(1, 0, 1, 12)
  训练集: 2006-01 至 2023-12 (216个月)
  测试集: 2024-01 至 2025-12 (24个月)

  模型信息准则:
    AIC: 823.95
    BIC: 858.20

  模型参数:

    ar.L2: 0.7329
    ar.L3: -0.9845

    ma.L2: -0.0793
    ma.L3: 1.6423

    ar.S.L12: 0.9932

  预测评估:

    季节性ARIMA模型能有效捕捉气温的年周期性变化

5.2 Holt-Winters降水预测模型
----------------------------------------
数学方法:
  三重指数平滑 (加法模型):
    水平方程: lₜ = α(yₜ/sₜ₋ₘ) + (1-α)(lₜ₋₁+bₜ₋₁)
    趋势方程: bₜ = β(lₜ-lₜ₋₁) + (1-β)bₜ₋₁
    季节方程: sₜ = γ(yₜ/lₜ) + (1-γ)sₜ₋ₘ

  预测评估:
    RMSE: 46.73mm
    MAE:  41.59mm

  模型评价:
    降水预测难度较大, RMSE在可接受范围内
    模型能较好捕捉降水的季节性模式
    对极端降水事件的预测能力有限

第十一章 深度学习时间序列预测
================================================================================

数学方法:
  TCN (Temporal Convolutional Network):
    因果卷积: yₜ = Σ f_k·xₜ₋ₖ, 输出仅依赖当前及历史, 不泄漏未来信息
    膨胀卷积: 第i层膨胀率 dᵢ = 2ⁱ, 感受野指数增长
      R = 1 + (k-1) × Σdᵢ, 3层(k=3)感受野15 > 序列长度12
    残差连接: x = ReLU(F(x) + x), 缓解深层梯度消失
  LSTM: 输入门iₜ/遗忘门fₜ/输出门oₜ与记忆单元cₜ, 缓解长程依赖梯度消失
    fₜ = σ(W_f·[hₜ₋₁,xₜ]+b_f), cₜ = fₜ⊙cₜ₋₁ + iₜ⊙tanh(W_c·[hₜ₋₁,xₜ]+b_c)
  GRU: 重置门rₜ与更新门zₜ, 参数更少, 训练更快
    hₜ = (1-zₜ)⊙hₜ₋₁ + zₜ⊙tanh(W·[rₜ⊙hₜ₋₁, xₜ])
  Transformer编码器: 缩放点积自注意力 + 多头注意力 + 可学习位置编码
    Attention(Q,K,V) = softmax(QKᵀ/√d_k)V, MultiHead = Concat(head₁..head_h)Wᴼ

11.1 模型配置
----------------------------------------
  输入特征: 38维 (地面气象24 + 干旱指数4 + 高空衍生7 + NDVI 1 + 月份周期2)
  序列长度: 12个月 (用过去12个月预测下1个月)
  模型体系: TCN / LSTM / GRU / Transformer (4种深度学习网络)
  隐藏单元: TCN通道[64,64,64] | LSTM/GRU隐层64×2层 | Transformer d_model=64, 4头×2层
  Dropout: 0.2
  优化器: Adam (lr=0.001), 微调 lr=0.0003
  策略: 4模型独立训练 + TCN 8站池化全局预训练迁移微调
  早停: patience=15 (微调 patience=10)
  最优选择: 按测试集RMSE为每站自动选择最优 (模型, 策略) 组合
